# مراجعة رفع التطبيق على Google Play (22 أكتوبر 2026)

## 1. شروط تقنية (اتصلحت)
- [x] **Target API 36 (Android 16):** إجباري لأي تطبيق جديد من 31 أغسطس 2026. كان 34، وبقى 36.
- [x] **الشاشة الكاملة (edge-to-edge):** من Android 15 التطبيق بيترسم تحت شريط الحالة والأزرار. اتظبط، والمحتوى بقى بعيد عنهم.
- [x] **زرار الرجوع الجديد (predictive back):** Android 16 مبقاش بيستخدم الطريقة القديمة، فاتحدّث الكود (OnBackInvokedCallback).
- [x] **صيغة AAB:** جوجل بلاي بياخد Android App Bundle مش APK. اتعمل `build-aab.sh` والملف `quran-karim-v3.3.aab`.
- [x] **مفتاح الرفع (upload key):** اتعمل `keys/upload.jks` وكلمة السر في `keys/upload-key.txt`. احتفظ بنسخة منهم برا المشروع. لو ضاع، جوجل تقدر تغيره (Play App Signing).
- [x] **الحجم:** حد الـ AAB الأساسي 200 ميجا. بعد رجوع الحرمين وطبقات التجويد لازم نراجع حجم الـ AAB عند البناء الجاي.
- [x] **الأذونات:** إنترنت (صوت القارئ) والموقع وقت شاشة القبلة بس. مفيش موقع في الخلفية، فمفيش إقرار إضافي.
- [x] **كود 64-bit:** التطبيق مفيهوش كود native، فمفيش مشكلة.

## 2. المحتوى وحقوق النشر
- [ ] **طبعة الحرمين:** رجعت في نسخة بلاي بطلبك (24 أكتوبر)، على أساس إن معاك إذن نشر من دار مصر. احتفظ بالإذن مكتوب، لأن جوجل ممكن تطلبه لو حد اشتكى. لو احتجت نسخة من غيرها: `PLAY=1`.
- [x] **طبعة الملك فهد والشمرلي:** مرسومين بخطوط مجمع الملك فهد، والمجمع مسموح بيه في البرامج والنشر الرقمي.
- [x] **النص والتفاسير والكتب:** مصادر مفتوحة ومذكورة في «حول التطبيق». نص quran-json رخصته CC BY-SA ومذكور.
- [x] **حول التطبيق:** فيه الإصدار والمصادر وحقوق النشر وفقرة الخصوصية.

## 3. سياسات المتجر
- [x] **سياسة الخصوصية:** مكتوبة في `store/privacy-policy.html` (عربي وإنجليزي). لازم تترفع على رابط عام.
- [x] **أمان البيانات (Data safety):** الإجابات في `store/listing.md`: التطبيق مش بيجمع بيانات.
- [x] **تصنيف المحتوى والجمهور:** الإجابات في `store/listing.md`.
- [x] **صفحة المتجر:** الاسم والوصف القصير والكامل، والأيقونة 512، وصورة العرض 1024×500، و5 لقطات شاشة، كلهم في `store/`.
- [ ] **اسم الحزمة (package):** `com.quran.karim`. لو جوجل قالت إنه مستخدم، لازم نغيّره قبل أول رفع، لأنه مبيتغيرش بعد كده.

## 4. المطلوب منك (مقدرش أعمله)
1. حساب مطوّر جوجل بلاي: play.google.com/console، رسوم 25 دولار مرة واحدة، وتأكيد الهوية ببطاقة رسمية.
2. رفع `privacy-policy.html` على رابط عام (مثلًا Google Sites أو GitHub Pages، وأقدر أساعدك فيها بإذنك)، وتحط بريدك مكان CONTACT_EMAIL.
3. **الاختبار المغلق:** الحسابات الشخصية الجديدة لازم تعمل closed testing مع 12 مختبر على الأقل لمدة 14 يوم متواصلة قبل ما تقدر تنشر للكل.
4. ترفع `quran-karim-v3.3.aab` وتملا الاستمارات من `store/listing.md`، وتبعته للمراجعة.
